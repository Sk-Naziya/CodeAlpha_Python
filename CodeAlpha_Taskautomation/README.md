# Automation Hub

A web-based Python automation project created for the CodeAlpha Internship.

## Features

### JPG Organizer
Moves uploaded JPG files into an organized folder.

### Email Extractor
Extracts all email addresses from text and saves them.

### Website Title Scraper
Scrapes the title of any webpage and saves it.

## Concepts Used

- os
- shutil
- re
- requests
- file handling
- Streamlit

## Run

streamlit run app.py
